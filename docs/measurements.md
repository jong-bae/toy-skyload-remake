# 원작 블랙박스 측정 기록 (M1)

> 원작 실행 파일은 열어 보지 않고, DOSBox 플레이 화면만 녹화·분석한 결과다. (context-notes D-03)
> 신뢰도: **상** 반복 측정 일치·오차 작음 / **중** 근거는 있으나 오차 10~20% / **하** 추정·미확정

## 1. 측정 환경

| 항목 | 값 |
|---|---|
| 원작 | `original_file/` 공식 프리웨어 배포본 (1995) 복사본을 `recordings/game/`에서 실행 |
| 에뮬레이터 | DOSBox 0.74, `tools/measure/dosbox-measure.conf` |
| CPU | `cycles=fixed 20000` |
| 녹화 | DOSBox 내장 녹화(ZMBV), 320×200, **70.086fps** |
| 자동화 | `tools/measure/drive.py` (키 입력, 화면 판별, 녹화 토글) |
| 분석 | `frames.py`(영상 로드), `gauge.py`(속도 게이지), `track.py`(지면 경계 추적), `ship.py`(우주선 위치) |

### 1.1 게임 시간 기준 (신뢰도 상)

- 같은 입력을 `cycles` 20000과 60000으로 녹화하고 가속 시작 시점을 맞추면, 같은 시각의 프레임이 픽셀 단위로 같다(평균 차이 0.00~0.03).
- 게임 진행은 CPU 속도와 무관하게 **실제 시간(타이머) 기준**이다. 같은 입력이면 결과가 결정론적으로 같다.
- 화면 갱신은 70Hz 프레임 중 일부에서만 일어난다(정지 시 약 18Hz, 고속 시 약 50Hz).

### 1.2 메뉴 입력

- 메뉴와 스테이지 선택 화면은 키를 약 0.25~0.3초 이상 눌러야 인식된다.
- 스테이지 선택 커서는 깜빡인다.

## 2. 화면 투영과 단위계 (신뢰도 상)

정지 화면의 노면 경계가 정확히 직선 `반폭 = (y − 32)`로 나온다.

| 항목 | 값 |
|---|---|
| 지평선(소실점) | 화면 y = **32** (200줄 중), x = 159.5 |
| 지면 행 y의 전진 거리 | **s = 1 / (y − 32)** — 단위 **K** (= 초점거리 × 카메라 높이 h) |
| 좌우 위치 | X / h = (x − 159.5) / (y − 32) |
| 높이 | 화면 높이차 Δy / (지면 행 − 32) = H / h |
| 우주선 접지 행 | y = 100 → 우주선 위치 s ≈ 0.0147 K |

- 리메이크에서 같은 투영(지평선 위치, 전진은 K 단위, 좌우·높이는 h 단위)을 쓰면 원작 화면이 그대로 재현된다. 원작의 화각(FOV)을 몰라도 된다.
- 카메라는 우주선을 따라 전진하며, 정지·점프 중에는 지평선과 노면이 움직이지 않는다(점프 시 우주선만 화면에서 올라감).

### 2.1 도로 칸(열) 폭 (신뢰도 상)

| 관찰 | 반폭 / (y − 32) | 칸 수 |
|---|---|---|
| 로드 3 외길 | 0.333 | 1 |
| 로드 0·4 중앙 노면 | 1.000 | 3 |
| 로드 1·4 넓은 구간 | 1.667 | 5 |

- **칸 1개 폭 = ⅔ h.** 우주선은 도로 중앙 칸에서 출발한다.
- 최대 7칸(반폭 2.333 h)은 원작 일반 정보 기준이며 아직 화면으로 확인하지 않았다.
- 우주선 스프라이트 폭은 29px(접지 행에서 칸 폭 45px) → 약 0.64칸.

### 2.2 전진 방향 길이 (신뢰도 하, 미확정)

- 로드 4 측면 블록 앞면 간격: **0.0350~0.0355 K** (등속 구간에서 3개 연속 일치).
- 로드 7 가로대 깊이 0.0084 K, 빈틈 0.0118 K.
- 위 값들의 공통 약수가 뚜렷하지 않아 **타일 1칸의 K 길이는 미확정**이다. 체크무늬처럼 한 칸짜리 지면 무늬가 반복되는 로드에서 다시 잰다.

## 3. 측정 결과

### M-01~M-03 전진 속도·가속

| 항목 | 값 | 신뢰도 |
|---|---|---|
| 속도 단계 | SPEED 게이지 약 **33단계** (게이지 1칸 = 300° 링 중 약 9°) | 상 |
| 가속 | 가속키를 누르는 동안 **0.118초(8.3프레임)마다 1단계**씩 일정하게 증가 → 0에서 최대까지 약 **3.8초** | 상 |
| 가속 곡선 | 선형 (등가속) | 상 |
| 자연 감속 | **없음.** 가속키를 떼면 속도 유지 (6단계에서 8.7초 등속 확인) | 상 |
| 6단계 등속 속도 | **0.0117 K/s** (궤적 직선 맞춤, 개별 궤적 0.0114~0.0122) | 중 |
| 최고 속도 추정 | 0.052~0.064 K/s (가속 구간 맞춤과 등속 측정이 약 20% 차이) | 하 |
| 감속키 동작 | 미측정 | — |

- 게이지가 실제 속도에 정확히 비례하는지는 고속 등속 측정을 하나 더 해서 확정해야 한다.

### M-05 점프 (정지 상태)

| 항목 | 중력 500 (로드 0) | 중력 400 (로드 6) | 신뢰도 |
|---|---|---|---|
| 체공 시간 | 0.499초 (35프레임) | 0.585초 (41프레임) | 상 |
| 최고 높이 | 0.588 h (40px) | 0.691 h (47px) | 상 |
| 초기 상승 속도 (4H/T) | 4.71 h/s | 4.72 h/s | 상 |
| 유효 중력 (8H/T²) | 18.9 h/s² | 16.2 h/s² | 중 |
| 착지 후 튕김 | 0.228초, 0.118 h | 0.385초, 0.147 h | 중 |

- 높이 곡선은 포물선이다. **점프 초기 속도는 중력과 무관하게 일정하고, 중력만 달라진다.**
- 표시 중력 비(500/400 = 1.25)와 측정 비(1.17)가 다르다. 두 점으로 맞추면 g ≈ 5.15 + 0.0275 × 표시값 (h/s²)이다. 중력 100인 로드 10을 측정해 확인해야 한다.
- **스페이스를 누르고 있으면** 착지 후 약 5프레임(0.07초) 만에 자동으로 다시 점프한다. 떼고 있으면 작게 한 번 튕긴 뒤 멈춘다.
- 이동 중 점프(점프 거리)는 미측정.

### M-08 정면 충돌

- 거의 최고 속도로 도로를 가로막은 블록 앞면에 부딪히면 **폭발**한다. (신뢰도 상, 1회 관찰)
- 폭발 후 화면이 페이드되고 약 **3.4초** 뒤 같은 로드 처음부터 다시 시작한다. (신뢰도 중)
- 폭발하지 않는 속도 경계는 미측정.

## 5. 측정 도구 사용법

```bash
python -m venv venv
venv/Scripts/python -m pip install -r tools/measure/requirements.txt
venv/Scripts/python tools/measure/drive.py <시나리오.json> [cycles]
```

- 시나리오 형식은 `drive.py` 상단 설명 참조.
- 원작 복사본(`recordings/game/`)과 화면 판별 기준 이미지(`recordings/ref/`)가 필요하다. 둘 다 git에서 제외된다.
- 실행 중에는 DOSBox 창이 맨 앞에 떠 있어야 한다. 다른 창이 앞으로 오면 키 입력을 멈추고 중단한다.
